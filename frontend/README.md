# frontend

React y TypeScript con Vite. Ejecuta npm ci y npm run dev; abre http://localhost:5173. Login/registro animados y administración de dispositivos. npm run build verifica tipos y genera dist. Toda petición de negocio atraviesa /api y el Gateway.

Lee también ../docs/ejecucion-y-alcance.md para límites y configuración de Supabase.
